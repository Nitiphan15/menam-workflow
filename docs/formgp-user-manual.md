# User Manual: FormGP - Grating Performance

อัปเดต: 10/07/2026

คู่มือนี้ใช้สำหรับบันทึกและตรวจสอบผลงาน Grating Performance ในระบบ Menam Workflow โดยอ้างอิงหน้าจอปัจจุบันของโมดูล FormGP

## 1. ภาพรวมระบบ

FormGP ใช้สำหรับบันทึกงานรายวันของทีม Grating แยกตามพนักงาน, MFG, ขั้นตอนงาน, เวลาเริ่ม-จบ, ยอดดี, ยอดเสีย และงานออกหน้างาน

เมนูหลักมี 4 หน้า

| หน้า | ใช้ทำอะไร |
|---|---|
| Dashboard | ดูสรุป KPI, ผลงานราย Step, รายพนักงาน, MFG ค้าง, Workload |
| Input รายวัน | บันทึกงานประจำวัน |
| Inquiry | ค้นหา, ตรวจสอบ, แก้ไข หรือลบรายการที่บันทึกแล้ว |
| Masters | ตั้งค่าพนักงาน, Step, Project และกิจกรรมหน้างาน |

สิทธิ์ที่เกี่ยวข้อง

| สิทธิ์ | ใช้งานได้ |
|---|---|
| GP | Dashboard, Input รายวัน, Inquiry |
| GPM | Masters และการตั้งค่า master |

URL ของระบบอยู่ภายใต้ `dp/grating-performance`

## 2. ก่อนเริ่มใช้งาน

ควรตรวจสอบข้อมูลในหน้า Masters ก่อนใช้งานจริง

1. มีรายชื่อพนักงานที่ใช้งานอยู่
2. มี Master Step ครบตามขั้นตอนที่ต้องการบันทึก
3. พนักงานแต่ละคนมี "งานที่รับผิดชอบ" เพื่อให้หน้า Input แนะนำ Step ที่เกี่ยวข้องได้
4. ถ้ามีงานออกหน้างาน ให้ตั้งค่า Step ที่เป็น "หน้างาน" และ Master กิจกรรมหน้างาน
5. ถ้าต้องเลือก Project จาก master ให้เพิ่ม Project และเลข SO ใน Master Project

## 3. การบันทึกงานในหน้า Input รายวัน

เข้าเมนู `Grating Performance > Input รายวัน`

### 3.1 กรอกข้อมูลหลัก

1. เลือกวันที่ทำงาน
2. เลือกพนักงานหลัก
3. ระบบจะแสดง Step ที่เกี่ยวข้องกับงานที่รับผิดชอบของพนักงานคนนั้น

หมายเหตุ: Step ที่แนะนำเป็นตัวช่วยเท่านั้น การบันทึกจริงให้เลือก Step จาก Master ที่ทำจริงในวันนั้น

### 3.2 เลือกขั้นตอนงาน

เลือก Step จาก Master ได้ 1 Step ต่อ 1 รายการบันทึก

ถ้า MFG เดียวกันทำหลาย Step ในวันเดียวกัน ให้เพิ่มรายการแยกเป็นคนละแถว เช่น

| กรณี | วิธีบันทึก |
|---|---|
| MFG G2600 ทำตัด-ขัด และแพ็ค | บันทึก 2 แถว แถวละ 1 Step |
| หลาย MFG ทำ Step เดียวกัน | ใช้ปุ่ม `เพิ่ม MFG` เพื่อเพิ่มแถว |
| งานออกหน้างาน | เลือก Step ที่เป็นหน้างาน แล้วกรอกข้อมูลหน้างาน |

### 3.3 บันทึก MFG ปกติ

ในส่วน "รายละเอียด MFG"

1. พิมพ์เลข MFG อย่างน้อย 2 ตัวอักษร
2. เลือก MFG จากรายการ autocomplete
3. ระบบจะเติมข้อมูลที่เกี่ยวข้อง เช่น Project, SO, Part, จำนวนเปิดแผน, kg/ชิ้น และ ตร.ม./ชิ้น
4. กรอกเวลาเริ่มและเวลาจบ
5. กรอกยอดดีและยอดเสีย
6. ติ๊ก "จบแล้ว" เมื่อรายการนั้นจบงานแล้ว
7. กรอกหมายเหตุถ้ามี
8. กด `บันทึก`

ระบบจะคำนวณบางค่าให้อัตโนมัติเมื่อมีข้อมูลจาก MFG

| ช่อง | วิธีคิด |
|---|---|
| ยอดดี (กก.) | ยอดดี (ชิ้น) x kg/ชิ้น |
| ยอดเสีย (กก.) | ยอดเสีย (ชิ้น) x kg/ชิ้น |
| ยอดดี ตร.ม. | ยอดดี (ชิ้น) x ตร.ม./ชิ้น |
| ยอดเสีย ตร.ม. | ยอดเสีย (ชิ้น) x ตร.ม./ชิ้น |
| ชั่วโมงงาน | เวลาจบ - เวลาเริ่ม |

ถ้าเวลาจบอยู่หลังเที่ยงคืน เช่น เริ่ม 22:00 จบ 01:00 ระบบจะนับเป็นข้ามวันให้

### 3.4 ข้อควรระวังเรื่องจำนวนเปิดแผน

ระบบตรวจสอบยอดชิ้นต่อ MFG + Step โดยใช้

`ยอดดี + ยอดเสีย`

ยอดรวมของ Step เดียวกันต้องไม่เกินจำนวนเปิดแผนของ MFG นั้น ถ้าเคยบันทึกไปแล้ว ระบบจะนับยอดเดิมรวมกับแถวที่กำลังบันทึกด้วย

ตัวอย่าง

| จำนวนเปิดแผน | บันทึกไปแล้ว | กำลังกรอก | ผลลัพธ์ |
|---:|---:|---:|---|
| 100 ชิ้น | 60 ชิ้น | 40 ชิ้น | บันทึกได้ |
| 100 ชิ้น | 60 ชิ้น | 45 ชิ้น | บันทึกไม่ได้ เพราะเกินแผน |

### 3.5 งานร่วมกับคนอื่น

ถ้างานเดียวกันมีหลายคนทำร่วมกัน

1. เลือกพนักงานหลักก่อน
2. ติ๊ก `ทำร่วมกับคนอื่น`
3. เลือกผู้ร่วมงานของ MFG นั้น
4. บันทึกยอดงานเพียงครั้งเดียวในแถวเดียว

ข้อสำคัญ: อย่าบันทึกงานเดียวกันซ้ำแยกคน เพราะจะทำให้ยอด MFG/Step ถูกนับซ้ำ

ระบบเก็บผู้ร่วมงานไว้กับรายการเดียวกัน เพื่อให้รายงานเห็นว่าใครร่วมทำงาน แต่ยอดงานยังอ้างอิงจากรายการบันทึกเดียว

### 3.6 งานออกหน้างาน

เมื่อเลือก Step ที่ตั้งค่าเป็น "หน้างาน" ระบบจะแสดงส่วนกิจกรรมหน้างาน

ต้องกรอกข้อมูลต่อไปนี้

1. เลือกกิจกรรมหน้างาน เช่น ดูหน้างาน Survey, วัดงาน, ติดตั้งงาน, ส่งงาน หรืออื่น ๆ
2. กรอกรายละเอียดงานหน้างาน
3. เลือก MFG ที่เกี่ยวข้องอย่างน้อย 1 รายการ
4. กรอก Project และเลข SO ของงานนั้น
5. กรอกเวลาเริ่ม-จบ
6. เลือกผู้ร่วมงานถ้ามี
7. กด `บันทึก`

งานหน้างานจะไม่ใช้ยอดดี/ยอดเสียแบบงานผลิตปกติ แต่จะใช้เพื่อสรุปชั่วโมงและงานที่เกี่ยวข้องกับ Project, SO และ MFG

## 4. การดูข้อมูลใน Dashboard

เข้าเมนู `Dashboard`

### 4.1 ตัวกรอง

สามารถกรองข้อมูลด้วย

| ตัวกรอง | ความหมาย |
|---|---|
| ช่วงสรุป | รายวัน, รายสัปดาห์, รายเดือน |
| จากวันที่ / ถึงวันที่ | ช่วงวันที่ที่ต้องการดู |
| MFG | ค้นหาเฉพาะ MFG |
| Project | ค้นหาเฉพาะ Project |
| เลข SO | ค้นหาเฉพาะ Sales Order |
| Step | ดูเฉพาะขั้นตอน |
| พนักงาน | ดูเฉพาะพนักงาน |

เมื่อเลือกช่วงสรุปเป็นรายสัปดาห์หรือรายเดือน ระบบจะช่วยปรับวันที่เริ่ม-สิ้นสุดของช่วงให้อัตโนมัติ

### 4.2 KPI ด้านบน

Dashboard แสดง KPI หลัก เช่น

| KPI | ความหมาย |
|---|---|
| MFG | จำนวน MFG ในช่วงที่เลือก |
| ยอดดีรวม | ยอดดีรวมเป็นชิ้น, กก. และ ตร.ม. |
| ยอดเสีย | ยอดเสียรวมเป็นชิ้น, กก. และ ตร.ม. |
| ชั่วโมงใช้จริง | ชั่วโมงจากเวลาเริ่ม-จบ |
| ชม./วัน | ชั่วโมงเฉลี่ยต่อวัน |
| เป้าหมาย (บาท) | เป้ายอดขาย D8 / FG GRATING |
| % Target | มูลค่างาน Pack เทียบกับเป้าหมาย |

เป้าหมาย D8 / FG GRATING ใช้ฐาน 1,700,000 บาทต่อเดือน ถ้าช่วงวันที่คร่อมหลายเดือน ระบบจะนับเดือนละ 1,700,000 บาทเต็ม

### 4.3 ตารางสรุปที่สำคัญ

| ส่วน | ใช้ดูอะไร |
|---|---|
| MFG ยังไม่ครบ / ยังไม่ Pack | MFG ที่ยังไม่จบ flow หรือยังไม่ถึง Pack |
| Slow Step | Step ที่ใช้เวลาสูงหรือมีประสิทธิภาพต่ำ |
| Efficiency รายคน x Step | ผลงานรายคนแยกตาม Step |
| คนทำงานตาม MFG x Step | MFG แต่ละ Step มีใครทำบ้าง |
| Workload รายวัน | ชั่วโมงงานแต่ละคนต่อวัน |
| รายคน | Top 10 ตามยอดดี และ % ของเสีย |
| ราย Step | ยอดและชั่วโมงแยกตาม Step |

## 5. การค้นหาและแก้ไขใน Inquiry

เข้าเมนู `Inquiry`

### 5.1 ตัวกรอง

สามารถกรองด้วยวันที่, MFG, Project, SO, Step และพนักงานได้เหมือน Dashboard

### 5.2 Mode การดูข้อมูล

| Mode | ใช้เมื่อ |
|---|---|
| Transaction | ดูรายการบันทึกแบบละเอียด แก้ไขหรือลบรายการ |
| By employee / day | ดูงานรวมรายพนักงานต่อวัน |
| By MFG / flow | ดู flow ของ MFG แยกตาม Step และคนทำ |

### 5.3 การแก้ไขรายการ

ใน Mode `Transaction`

1. กดปุ่มแก้ไขของรายการที่ต้องการ
2. แก้วันที่, Step, เวลา, ยอดดี, ยอดเสีย, Project, SO, กิจกรรมหน้างาน หรือหมายเหตุ
3. กดบันทึกแก้ไข

ระบบจะตรวจสอบจำนวนเปิดแผนอีกครั้งเมื่อแก้ยอดชิ้นหรือเปลี่ยน Step

### 5.4 การลบรายการ

ใน Mode `Transaction`

1. กดปุ่มลบ
2. ยืนยันการลบ

เมื่อลบแล้ว รายการนั้นจะไม่ถูกนำไปคำนวณใน Dashboard หรือ Inquiry

## 6. การตั้งค่าใน Masters

หน้า Masters ใช้สิทธิ์ `GPM`

### 6.1 Master พนักงาน

ข้อมูลที่ตั้งค่าได้

| ช่อง | ความหมาย |
|---|---|
| รหัสพนักงาน | รหัสอ้างอิงพนักงาน |
| ชื่อ | ชื่อที่แสดงในระบบ |
| ชื่อเล่น | ใช้ช่วยค้นหา/ระบุคน |
| งานที่รับผิดชอบ | Step หรือกิจกรรมที่เกี่ยวข้องกับพนักงาน |
| นักศึกษา | ระบุช่วงฝึกงาน 3, 6, 12 เดือน หรือกำหนดเอง |
| สถานะ | เปิด/ปิดการใช้งาน |

งานที่รับผิดชอบจะนำไปใช้แนะนำ Step ในหน้า Input

### 6.2 Master Step งาน

ข้อมูลที่ตั้งค่าได้

| ช่อง | ความหมาย |
|---|---|
| Code | รหัสระบบ ใช้ A-Z, 0-9, `_`, `-` |
| ชื่อขั้นตอน | ชื่อ Step ที่ผู้ใช้เห็น |
| Target ชิ้น/ชม. | เป้าหมายหลักสำหรับงานที่วัดเป็นชิ้น |
| Target กก./ชม. | เป้าหมายเสริมสำหรับงานที่วัดเป็นน้ำหนัก |
| Sort | ลำดับการแสดงผล |
| หน้างาน | ระบุว่า Step นี้เป็นงานออกหน้างานหรือไม่ |
| สถานะ | เปิด/ปิดการใช้งาน |

มีปุ่ม `เติมชุดขั้นตอนมาตรฐาน` เพื่อสร้าง Step เริ่มต้นให้ระบบ เช่น เชื่อมประกอบ, ล้างรอยเชื่อม, แช่ passivate, EPQ, spot แผ่นเกรตติ้ง, ตัด-ขัด, เลเซอร์, แพ็ค และออกหน้างาน

### 6.3 Master Project

ใช้สำหรับ Project autocomplete ร่วมกับข้อมูล Project ที่ดึงจาก workorder.notes

ข้อมูลที่ตั้งค่าได้

| ช่อง | ความหมาย |
|---|---|
| Project | ชื่อโครงการ |
| เลข SO | เลข Sales Order ที่เกี่ยวข้อง |
| Sort | ลำดับการแสดง |
| สถานะ | เปิด/ปิดการใช้งาน |

### 6.4 Master กิจกรรมหน้างาน

ใช้เป็นตัวเลือกเมื่อบันทึก Step ที่เป็นงานออกหน้างาน

ข้อมูลที่ตั้งค่าได้

| ช่อง | ความหมาย |
|---|---|
| Activity code | รหัสกิจกรรม ใช้ A-Z, 0-9, `_`, `-` |
| Activity name | ชื่อกิจกรรมที่แสดงในหน้า Input |
| Sort | ลำดับการแสดง |
| สถานะ | เปิด/ปิดการใช้งาน |

## 8. ข้อผิดพลาดที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| บันทึกไม่ได้เพราะไม่พบ MFG | พิมพ์ MFG แต่ไม่ได้เลือกจาก autocomplete | คลิกเลือก MFG จากรายการที่ระบบแสดง |
| kg หรือ ตร.ม. ไม่คำนวณ | MFG ไม่มี metadata เช่น kg/ชิ้น หรือขนาด W/L | ตรวจสอบข้อมูล MFG หรือกรอกยอดที่จำเป็น |
| จำนวนชิ้นเกินแผน | ยอดดี + ยอดเสีย รวมกับยอดเดิมเกินจำนวนเปิดแผน | ตรวจสอบยอดเดิมใน Inquiry แล้วปรับให้ถูกต้อง |
| ไม่เห็น Step ที่ต้องการ | Step ถูกปิดสถานะ หรือยังไม่มีใน Master | ให้ผู้มีสิทธิ์ GPM เปิด/เพิ่ม Step |
| ไม่เห็น Masters | ผู้ใช้ไม่มีสิทธิ์ GPM | ขอเพิ่มสิทธิ์ GPM |
| งานร่วมถูกนับยอดสูงผิดปกติ | บันทึกซ้ำแยกคนแทนการใช้ผู้ร่วมงาน | ลบรายการซ้ำ แล้วใช้รายการเดียวพร้อมเลือกผู้ร่วมงาน |

## 9. แนวทางการใช้งานที่แนะนำ

1. บันทึกงานให้เร็วที่สุดหลังจบกะ เพื่อให้เวลาและยอดตรงกับหน้างานจริง
2. เลือก MFG จาก autocomplete เสมอ เพื่อให้ระบบดึงข้อมูลประกอบมาครบ
3. ใช้ `ทำร่วมกับคนอื่น` เมื่อหลายคนทำงานเดียวกัน
4. แยกแถวเมื่อเป็นคนละ Step หรือคนละ MFG
5. ตรวจ Inquiry หลังบันทึก เพื่อยืนยันว่ารายการถูกต้อง
6. ตรวจ Dashboard รายวันเพื่อดู MFG ค้าง, Slow Step และ Workload
7. ให้หัวหน้างานหรือผู้มีสิทธิ์ GPM ดูแล Master ให้สะอาดและไม่ซ้ำ
