# เพิ่ม User หลายคนพร้อมกัน

คำสั่งนี้รับไฟล์ `.csv`, `.xlsx` หรือ `.xls` และสร้าง User พร้อมผูกแผนก/ตำแหน่งใน
workflow SQL Server

## รูปแบบไฟล์

ใช้ไฟล์ตัวอย่าง `database/templates/bulk_users.csv` ซึ่งมี 4 คอลัมน์:

| ชื่อ | รหัสพนักงาน | แผนก | ตำแหน่ง |
| --- | --- | --- | --- |
| สมชาย ใจดี | EMP001 | IT | Staff |

- แผนกและตำแหน่งใส่ได้ทั้ง `code` หรือ `name` แต่ต้องตรงกับข้อมูล Active ในระบบ
- ถ้าชื่อซ้ำจนระบุไม่ได้ ให้ใช้ `code`
- รหัสพนักงานใน Excel ควรกำหนดรูปแบบเซลล์เป็น Text เพื่อรักษาเลข `0` ด้านหน้า
- สามารถเพิ่มคอลัมน์ `email` และ `password` รายคนได้ แต่ไม่บังคับ

## ตรวจสอบก่อนบันทึก

```powershell
php artisan users:bulk-import "C:\import\users.xlsx" `
  --default-password="รหัสเริ่มต้นอย่างน้อย 6 ตัว" `
  --dry-run
```

คำสั่งจะตรวจทุกแถวก่อน เช่น คอลัมน์ไม่ครบ รหัสพนักงาน/อีเมลซ้ำ ไม่พบแผนก
หรือตำแหน่งไม่อยู่ในแผนก โดย `--dry-run` จะไม่สร้างข้อมูล

## บันทึกจริง

```powershell
php artisan users:bulk-import "C:\import\users.xlsx" `
  --default-password="รหัสเริ่มต้นอย่างน้อย 6 ตัว"
```

ถ้าไม่มีคอลัมน์ `email` ระบบจะสร้างเป็น
`รหัสพนักงาน@menam.local` โดยเปลี่ยน domain ได้ด้วย `--email-domain`

การนำเข้าเป็นแบบ all-or-nothing: หาก validation ไม่ผ่านหรือเกิดข้อผิดพลาดระหว่าง
บันทึก ระบบจะไม่ทิ้ง User ที่สร้างค้างไว้บางส่วน

คำสั่งนี้ผูกเฉพาะแผนกและตำแหน่งจริง (`department_role_users`) ยังไม่ให้สิทธิ์เมนูเว็บ
ซึ่งต้องกำหนดภายหลังตามหน้าจัดการสิทธิ์ของระบบ
